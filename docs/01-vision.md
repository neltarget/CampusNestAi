# CampusNest AI
## Vision Document

Version: 2.0

---

# Overview

CampusNest AI is a demonstration project built to showcase Agentic AI principles through a realistic accommodation search experience for university students.

The project is intentionally small.

Its goal is not to build the next Airbnb.

Its goal is to demonstrate how a single AI orchestrator can reason through a complex problem using structured thinking, deterministic services, and clear explanations.

The emphasis is on AI reasoning, orchestration, explainability, and simplicity.

---

# The Problem

Finding accommodation around universities is often difficult.

Students typically:

- search WhatsApp groups
- ask friends
- walk around neighborhoods
- call landlords individually
- compare prices manually

Information is often:

- incomplete
- outdated
- duplicated
- inconsistent

Traditional accommodation websites simply display listings.

CampusNest AI demonstrates how AI can actively assist students in making better decisions.

---

# Vision

Build an intelligent accommodation assistant that understands a student's needs, searches available listings, evaluates options, verifies listing quality, and explains recommendations through a single AI orchestrator.

---

# Demo Objectives

The demonstration should clearly show:

✓ Natural language understanding

✓ Deterministic search

✓ AI reasoning

✓ Explainable recommendations

✓ Structured AI outputs

✓ One API call per search

---

# Target Users

Primary

University students searching for accommodation.

Secondary

Developers learning Agentic AI.

---

# Demo Scope

One university.

Approximately 25 accommodation listings.

Simple React frontend.

Node.js backend.

Supabase database.

OpenAI API.

No production infrastructure.

---

# Success Criteria

The project is successful if a visitor can:

1. Ask for accommodation naturally.
2. Observe the AI orchestrator processing the request.
3. Receive ranked recommendations.
4. Understand WHY those recommendations were chosen.

The AI reasoning should be the main attraction.
